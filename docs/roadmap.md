# Product Roadmap & Milestones

The roadmap for People Hub HRMS SaaS is structured in stages:

## Phase 1: Architectural Foundation (Complete)
* [x] Monorepo setup with workspace package mapping.
* [x] Logical Multi-Tenant database isolation layer (Prisma Extensions).
* [x] Auth systems supporting JWT contexts, multi-role scopes, and user switching.
* [x] Swagger OpenAPI definitions.
* [x] Modular SaaS settings & admin settings screen.
* [x] System audit logging.

## Phase 2: Core HRMS Modules
* [ ] Employee Profiles and complete onboarding workflows.
* [ ] Leave entitlement configurations & request managers.
* [ ] Shift allocation, rosters, and daily timesheet logs.
* [ ] Payroll engine computing piece-rate, muster-roll, and OT allowances.

## Phase 3: Mobile & Integrations
* [ ] Bootstrap the Flutter application.
* [ ] Consume REST APIs with zero modifications to core backends.
* [ ] Biometric sync modules.
* [ ] Push notification setups.
